Tiêu đề trường upload hiển thị phía trên control. Mô tả phụ giúp người dùng hiểu yêu cầu upload. Giới hạn nhóm file cho phép tải lên. Dung lượng tối đa mỗi file, đơn vị MB. Số lượng file tối đa cho phép chọn. Đánh dấu trường upload là bắt buộc. Khoá thao tác click, kéo thả và chọn file.
Tương tác Upload File
