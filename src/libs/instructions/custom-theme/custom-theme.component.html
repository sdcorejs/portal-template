Import mixin sd.theme() từ @sdcorejs/angular/assets/scss/themes/default và truyền map màu cần ghi đè. Mixin merge với bộ mặc định rồi sinh ra toàn bộ --sd-* CSS custom properties cho tất cả sd-* components.

Material components dùng palette M2 với 10 shade (50→900) và map contrast. Nhập màu gốc bên dưới để tự động sinh palette — sau đó copy SCSS vào styles.scss. Thông thường cần 3 palette: primary, accent (thường dùng lại success), và warn (map với error).
