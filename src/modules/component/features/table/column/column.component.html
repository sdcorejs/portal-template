Cột Tên
Render header riêng qua title.templateRef, vẫn giữ title dạng text để export/config dùng. Render thân ô bằng cell.templateRef, context nhận {{ snippetCellContext }}. Bật cell.copiable để hiện nút copy nội dung cell khi hover.
Cột Ghi chú
Rút gọn nội dung dài qua cell.truncate.enable, kiểu hiển thị đầy đủ: type: 'tooltip' hoặc 'more'.
Cột Trạng thái
Header có icon nhấn mạnh trạng thái. Thay text mặc định bằng sd-switch: click để đổi item.isActive ngay trong bảng.
Cách custom cột sd-table:
  • Custom title — đặt title dạng ColumnTitleOption: {{ snippetTitleOption }}. Field title vẫn giữ text gốc để export/config-column nhận dạng.
  • Custom cell — đặt cell.templateRef. Template nhận context let-item="item", let-column="column", let-autoId="autoId".
  • Cell tương tác — đặt control (vd. sd-switch) trong cell template và emit event ra component để mutate item. Demo: cột Trạng thái bind [model]="item.isActive" + (modelChange).
  • Copy — cell.copiable: true. Truncate — cell.truncate: {{ snippetTruncateOption }}.
